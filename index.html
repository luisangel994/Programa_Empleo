⚡ Configuración Real de Notificaciones (Email SMTP & Bot Telegram)

Introduce tus datos reales para que el navegador y el script en Python puedan enviarte mensajes directos a tu email o Telegram.

💡 ¿Cómo hacer que funcionen los avisos reales?
  • Telegram (Envío Inmediato desde la Web): 1. En Telegram busca @BotFather y escribe /newbot para crear tu bot y obtener tu Token. 2. Busca @userinfobot y escribe cualquier mensaje para ver tu Chat ID. 3. Pégalos arriba y haz clic en "💬 Probar Bot de Telegram Real". ¡Te llegará una notificación al instante!
  • Email (Envío vía Python / Gmail): Google requiere una Contraseña de Aplicación de Gmail para enviar emails automáticos sin bloquearse. Ejecuta en tu ordenador python test_send.py para probarlo de forma interactiva en 10 segundos.
